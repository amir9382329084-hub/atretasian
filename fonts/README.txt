فونت‌های پیشنهادی تاسیان

در CSS ترتیب اولویت فونت‌ها این‌گونه تنظیم شده است:
Doran, Vazir, Kalameh, Graphic, Vazirmatn, Tahoma

برای استفاده از فونت‌های Doran، Vazir، Kalameh و Graphic باید فایل‌های فونت دارای مجوز استفاده را روی ویندوز نصب کنید.
پس از نصب، مرورگر و پروژه را دوباره باز کنید. اگر فونتی نصب نباشد، مرورگر به فونت بعدی در فهرست می‌رود.

فایل فونت‌های تجاری/دارای مجوز در این بسته قرار نگرفته‌اند؛ چون مجوز بازتوزیع آن‌ها مشخص نیست.
